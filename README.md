
# 📈 Dashboard de Movimentação | Power BI

Dashboard interativo que acompanha a movimentação financeira por mês e por cidade, comparando **faturamento** e **custo** e mostrando a **margem de lucro**.

🔗 **[Alguns Dashboard no meu Portfólio ](https://sites.google.com/view/portifoliosamuelmarianomelo/in%C3%ADcio)**

## ✨ Recursos

- Indicadores de **Total Faturamento**, **Total Custo** e **Margem de Lucro**
- Evolução mensal de faturamento e custo em um único gráfico
- Proporção entre custo e margem de lucro
- Filtro por cidade

## 🛠️ Tecnologias

Power BI Desktop · DAX · Power Query

## 🚀 Como abrir

Baixe o arquivo `.pbix` e abra no **Power BI Desktop**.
